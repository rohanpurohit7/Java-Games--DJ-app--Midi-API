This folder intentionally contains no commercial audio. Add only WAV/AIFF files that you created or are licensed to use.

Equivalent `.aiff` filenames are also accepted.

Recommended master format:

- 24-bit PCM
- 44.1 kHz or 48 kHz
- normalized with sufficient headroom
- no lead guitar, leaving space for improvisation
- consistent downbeat and loop boundaries

At runtime, choose the containing folder with **CHOOSE LOSSLESS BACKING LIBRARY**. The application does not require the files to be committed to Git.
